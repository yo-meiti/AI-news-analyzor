Data Flow (RSS → Analysis → Image → Telegram):
 1. RSS item → Render Django bridge (render-bridge) 
 2. Bridge → POST /api/chat (analyzer worker) → Analysis results stored in D1
 3. Bridge → POST /api/prompts (prompt-generator) → English prompt for image
 4. Bridge → POST /api/generate-to-telegram (image worker) → Image generated + sent to bot
 5. Image worker → POST /notify (telegram bot) → Message + image published to @thefuturedge channel

 1. Create account on Render.com
 2. Connect GitHub or upload repo
 3. Set environment variables (see render-bridge/README.md):

 5. Schedule cron job or POST to /run_rss endpoint manually

Once deployed, the bridge will:
 - Fetch RSS feeds
 - Rank/deduplicate articles
 - Send through the worker pipeline
 - Post results to Telegram automatically
